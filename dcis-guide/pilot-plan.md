# Pilot Plan

## Goal

Prove that a camera-first, conversational guide can make one part of DCIS more engaging and can help build the museum knowledge base during use.

## Pilot Scope

Choose one small area:

- one room
- one exhibit case
- one wall
- one cluster of 10-20 objects

The best pilot area should have:

- objects visitors already ask about
- visible labels
- guide knowledge that is not fully captured elsewhere
- local DCIS significance
- enough visual variety for camera recognition

## Inputs Needed From DCIS

- rough floor plan or sketch
- photos/video of the pilot area
- labels visible in the area
- any existing tour notes
- recorded walkthrough from Brendan or a guide
- list of known highlights
- common visitor questions
- any relevant collection records

## Prototype Features

The interface can be prototyped quickly, but AI and vision claims should be validated with real DCIS images, frames, OCR, and guide responses rather than fake recognition.

### Visitor Mode

- camera view
- "what am I looking at?" response
- short guide explanation
- ask-anything chat
- recommended next object
- one simple quest or challenge

### Builder Mode

- record a walkthrough
- capture photos
- transcribe guide narration
- save labels/OCR text
- add corrections
- mark highlights
- generate proposed object/zone records

### Review Mode

- approve/edit generated records
- mark confidence
- publish selected guide content
- view unanswered visitor questions

## First Test

Run a private walkthrough:

1. Brendan or a guide walks the pilot area with the app.
2. They talk naturally about what matters.
3. The app creates rough records and tour stops.
4. Staff reviews the output.
5. A test visitor tries the guide.
6. Measure whether the visitor keeps using it and moves to another object.

## Prototype Success

The pilot works if:

- a visitor can understand where they are in the exhibit
- the guide says something more engaging than a label
- visitors ask questions naturally
- the app can capture useful staff knowledge
- the back-office review process improves the guide
- staff can imagine expanding it room by room
